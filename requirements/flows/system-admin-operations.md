# System Admin Operations

1. System admin opens the root dashboard at `admin.nekomin.com`.
2. Backend returns a dashboard summary of tenants, tenant setup gaps, and recent tenants.
3. System admin opens a tenant and can view tenant provisioning status.
4. System admin can manage the tenant admin account: reset password, change email, enable, or disable.
5. System admin can view tenant admin users without relying on current tenant context.
6. System admin can check the tenant R2 bucket and custom domain status.
7. System admin can retry attaching the R2 custom domain.
8. System admin can archive a tenant as a soft-delete action.
